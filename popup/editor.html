Ship Custom Scripts

Add .user.js files to scripts/ and entries such as {"id":"my-helper","file":"my-helper.user.js","enabled":true} to scripts/scripts.json, then reload the extension. Rescanning restores missing imports while preserving saved edits and enabled states. Folder scripts are protected from deletion in the toolbox; disable them instead. Export Extension ZIP creates a fresh, ready-to-share extension folder with all saved scripts. Recipients still need to enable Allow User Scripts and grant their own site access. Remote @require and @resource dependencies may need network access.

Supported Script Features

@match, @include, exclusions, @run-at, @noframes, @inject-into, @grant, @connect, @require and @resource use the existing toolbox runtime. GM_* and GM.* values, styles, menus, networking, downloads and AO toolbox helpers remain available. For page fetch/XHR interception, use page injection and document-start, then reload the website.

Compatibility is not complete: cloud sync, automatic @updateURL updates, GM_cookie and GM_getTab/GM_saveTab are not implemented. document-body currently runs at document-end. Large downloads should use GM_download or the built-in Media tools rather than the GM_xmlhttpRequest binary reply (60 MB limit).

PDFs

Open a PDF in the ALLEN viewer, then use Media > Open or Save. The toolbox tries the fresh authorized stream first and keeps the old captured-blob method as a fallback. A complete PDF already captured from that viewer can still open and save if the stream request fails. Blob-only PDFs remain supported. If neither method has a complete PDF, reopen the viewer to capture a fresh token.
