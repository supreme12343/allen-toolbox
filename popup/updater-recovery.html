Recovery and Help

This page is independent of the toolbox background and other JavaScript modules. Opening it does not grant folder permission or start recovery.

Stop other work before recovering.

Finish or cancel active downloads in ALLEN Toolbox and Chrome. Use this extension folder only in this browser/profile. Recovery cannot see work in another browser/profile and must not run alongside it.

Folder updates are not atomic. Recovery can fail if the saved journal, folder ownership, permission, or original bytes are unavailable or changed. A separate known-good backup is still important. Do not move or edit the extension folder during recovery.

Saved recovery state

Checking for a saved recovery journal...

No recovery changes have been made by opening this page.

Chrome may ask for read/write access after you click Reconnect folder permission. The saved folder must match the recovery journal; a different folder cannot be adopted during recovery.

Restore previous files uses the saved pre-update bytes when a matching journal and owned folder are available. Stop downloads first. It does not install another release or promise that every interruption is repairable.

Reload is offered only after verified recovery finishes and the saved journal is cleared. Read the recovery result before reloading.

If recovery is unavailable

  1. Keep all browsers and profiles that use this folder idle. Do not delete the saved extension data or replace files while recovery is running.
  2. Reconnect permission only with the button above. If a recovery journal is available, restore the previous files and read the result.
  3. If recovery cannot complete, retain the original folder location and restore a separate known-good backup manually. Check the files before reloading at Chrome's extension management page.
