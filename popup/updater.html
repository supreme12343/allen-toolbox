Unpacked extension / signed releases

Folder updates, with your permission.

Connect the original unpacked extension folder once to install signed official updates entirely in Chrome. This is a full-tab setup, not a toolbar popup.

One folder. One browser/profile. Per-file updates.

Use this folder only in this browser/profile. Other browsers or profiles cannot be coordinated. Updating several files is not atomic: interruption, local edits, or lost permission can leave an update incomplete. Recovery has limits. Keep a separate known-good backup.

No Store installation, executable, PowerShell, or Windows helper is used by this updater.

01

Remember the original folder

For first-time setup, select the allen-toolbox folder containing manifest.json, not its parent or a second copy.

Choose once and grant Chrome read/write access. The updater checks that this is the currently loaded extension folder and remembers its handle in this browser/profile. Connecting or restoring access does not install an update.

Required when choosing a folder or turning automatic file installation on. Restoring access to the remembered folder does not require a new acknowledgement.

02

Decide how files are installed

Automatic file installation is off by default.

Enable only after connecting the folder, granting read/write access, and acknowledging the safety limits. When on, verified releases may replace files without another install click while the browser is open. Active toolbox work defers installation; revoked permission pauses it without resetting your choice. You can turn this off without folder permission. This does not make cross-profile use safe.
