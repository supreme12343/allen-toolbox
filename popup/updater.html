Experimental / 2.3.1 BETA

Folder updates, with your permission.

Connect the original unpacked extension folder to test signed beta updates entirely in Chrome. This is a full-tab setup, not a toolbar popup.

One folder. One browser/profile. Beta risks.

Use this folder only in this browser/profile. Other browsers or profiles cannot be coordinated. Updating several files is not atomic: interruption, local edits, or lost permission can leave an update incomplete. Recovery has limits. Keep a separate known-good backup.

No Store installation, executable, PowerShell, or Windows helper is used by this updater.

01

Connect the original folder

Select the allen-toolbox folder containing manifest.json, not its parent or a second copy.

Chrome will ask you to grant read/write access. The updater checks that this is the currently loaded extension folder before writing extension code. Selecting a folder does not install an update.

02

Decide how files are installed

Automatic file installation is off by default.

Enable only after connecting the folder, granting read/write access, and acknowledging the beta risks. When on, verified beta releases may replace files without another install click while the browser is open. Active toolbox work defers installation; revoked permission pauses it. This does not make cross-profile use safe.
